# 1. 松灵piper机械
## 1.1 查看机械臂can口
```bash
for device in /sys/class/net/*; do
  [ "$(cat "$device/type" 2>/dev/null)" = "280" ] || continue
  serial=$(udevadm info --query=property --path="$device" | sed -n 's/^ID_SERIAL_SHORT=//p')
  echo "$(basename "$device"): $serial"
done

```

## 1.9 端侧推理

Windows 本地电脑（`192.168.41.1`）负责加载 BF16 模型并使用 RTX 5080 推理，Ubuntu 天钡（`192.168.41.2`）负责读取三路相机、发送观测和控制双臂。先启动 Windows 服务，再启动 Ubuntu 客户端；两端控制频率均为 30 Hz。

### 1.9.1 Windows 端启动服务（PowerShell）

使用已配置好的 `pi05-server` 环境一键启动，无需手动激活环境：

```powershell
& E:\ABYT\a0810\start_pi05_server.ps1
```

也可以在 PowerShell 中执行下面的等效命令（二选一）：

```powershell
Set-Location E:\ABYT\a0810\Evo-RL-data
$env:PYTHONUTF8 = "1"
$env:HF_HUB_OFFLINE = "1"
$env:TRANSFORMERS_OFFLINE = "1"

& E:\ABYT\a0810\venvs\pi05-server\Scripts\python.exe -m lerobot.async_inference.policy_server `
  --host=0.0.0.0 `
  --port=8099 `
  --fps=30 `
  --inference_latency=0.033 `
  --obs_queue_timeout=2
```

服务启动后等待客户端连接；收到客户端的模型配置后才开始加载模型。首次加载实测约 46 秒，首轮预热推理约 17 秒，预热后模拟观测推理约 0.33 秒/动作块。启动时保持该终端运行。

### 1.9.2 Ubuntu 端启动整钞推理（Bash）

在 Ubuntu 上安装了本仓库、CAN 和 RealSense 依赖的环境中执行：

```bash
conda activate evo-rl

python -m lerobot.async_inference.robot_client \
  --server_address=192.168.41.1:8099 \
  --robot.type=bi_piper_follower \
  --robot.left_arm_config.port=can3 \
  --robot.right_arm_config.port=can2 \
  --robot.id=my_bi_piper_follower \
  --robot.left_arm_config.cameras="{fixed: {type: intelrealsense, serial_number_or_name: '263122074897', width: 640, height: 480, fps: 30}, wrist: {type: intelrealsense, serial_number_or_name: '263122072536', width: 640, height: 480, fps: 30}}" \
  --robot.right_arm_config.cameras="{wrist: {type: intelrealsense, serial_number_or_name: '262722075213', width: 640, height: 480, fps: 30}}" \
  --task="Pick up the banknotes from the desk, straighten them neatly and hand them over to the customer." \
  --policy_type=pi05 \
  --pretrained_name_or_path=E:/ABYT/a0810/models/straighten1110_to_1111_pi05/pretrained_model \
  --policy_device=cuda:0 \
  --client_device=cpu \
  --fps=30 \
  --actions_per_chunk=50 \
  --chunk_size_threshold=0.5 \
  --debug_visualize_queue_size=True \
  --robot.left_arm_config.require_calibration=false \
  --robot.right_arm_config.require_calibration=false
```

- `--pretrained_name_or_path` 由 Windows 服务端解析，因此填写 Windows 上的模型目录；Ubuntu 无需复制模型权重。
- `--policy_device=cuda:0` 指 Windows 服务端的显卡；Ubuntu 客户端使用 `--client_device=cpu`。
- 模型配置已设为 `bfloat16`，tokenizer 已配置为 Windows 本地目录 `E:/ABYT/a0810/models/paligemma-3b-pt-224`。
- 若 Ubuntu 环境名称不是 `evo-rl`，将激活命令替换为实际环境；整钞任务描述应与训练时使用的描述保持一致。
- 已通过真实模型与模拟三路图像的 gRPC 测试，机械臂和真实相机仍需在 Ubuntu 端联调。
